# DaemonONE — Research Paper

### Towards a Unified Local-First Computing Environment for Multi-Device Development

This repository contains the LaTeX source and compiled PDF of an undergraduate research paper proposing **DaemonONE**, a decentralized, peer-to-peer, local-first computing environment for multi-device development.

DaemonONE aims to provide a unified view of computing resources across multiple personal devices while preserving their independence, local autonomy, and existing operating environments.

## Repository Structure

```text
DaemonONE/
├── main.tex        # LaTeX source
├── main.pdf        # Compiled research paper
├── images/         # Figures and diagrams
└── papers/         # Research papers and reference materials
```

## Compilation

### Requirements
- TeX Live or MiKTeX
- A LaTeX editor (TeXworks, TeXstudio, or VS Code with LaTeX Workshop)

### Instructions

1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd DaemonONE
   ```

2. Open `main.tex` in your preferred LaTeX editor.

3. Compile using the configured LaTeX engine to generate `main.pdf`.
