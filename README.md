\# DaemonONE — Research Paper



\*\*Towards a Unified Local-First Computing Environment for Multi-Device Development\*\*



This repository contains the LaTeX source and compiled PDF of our undergraduate research paper on \*\*DaemonONE\*\*, a proposed local-first distributed computing environment for personal multi-device development.



\## Repository Structure



\- `main.tex` — LaTeX source of the research paper.

\- `main.pdf` — Compiled research paper.

\- `images/` — Figures and diagrams used in the paper.

\- `papers/` — Research papers and reference material reviewed during the study.



\## Compilation



\*\*Requirements:\*\*

\- TeX Live or MiKTeX

\- TeXworks or another LaTeX editor



Open `main.tex` in a LaTeX editor and compile using the configured LaTeX engine.
